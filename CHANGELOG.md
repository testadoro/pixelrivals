# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024

### Added
- Initial Unity URP project structure
- PlayerController with virtual joystick support
  - Movement with CharacterController
  - Basic attack with projectiles
  - Special ability (triple shot spread)
  - Health system
- BotAI with autonomous behavior
  - Patrol mode
  - Chase and attack modes
  - Configurable detection and attack ranges
- Projectile system
  - Linear movement
  - Team-based collision detection
  - Damage dealing
  - Auto-destruction after lifetime
- ConquestZone capture mechanics
  - Team-based capture progress
  - Visual feedback with material changes
  - Trigger-based player/bot detection
- Mobile UI system
  - VirtualJoystick for movement
  - Attack button
  - Special ability button with cooldown indicator
  - Health bar display
  - Conquest zone status display
- GameManager for match setup
  - Bot spawning system
  - Match timer
- Comprehensive documentation
  - README with project overview
  - SETUP_GUIDE with detailed scene setup instructions
  - ARCHITECTURE document with system design
- Unity configuration files
  - Package manifest with URP dependencies
  - Project settings for mobile development
  - Input manager configuration
  - Tag manager with Player and Environment tags

### Technical Details
- Unity Version: 2022.3.10f1 or later
- Render Pipeline: Universal Render Pipeline (URP) 14.0.8
- Target Platform: Mobile (Android/iOS)
- Input System: Legacy with virtual controls

### Known Limitations
- No .meta files (generated by Unity on project load)
- No prefabs (must be created in Unity Editor)
- No materials (default materials used)
- No scene files (must be set up manually)
- Basic AI without advanced pathfinding
- No object pooling for projectiles
- No audio system
- No animations
- No networking/multiplayer
